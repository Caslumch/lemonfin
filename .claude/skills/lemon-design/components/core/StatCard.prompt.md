Summary KPI card: icon chip, label, big Outfit value, sub-line. `tone="dark"` is the highlighted black balance card; `valueColor` tints the number for income/expense.

```jsx
<StatCard tone="dark" label="Total Balance" value="R$ 6.556,73" icon={<WalletIcon/>} />
<StatCard label="Saídas" value="R$ 70,00" sub="3 transações" valueColor="danger" icon={<TrendDownIcon/>} iconTone="danger" />
```
